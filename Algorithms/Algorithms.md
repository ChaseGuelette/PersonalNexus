# Algorithms

> Part of [[BRAIN-INDEX]]

The mathematical heart of PersonalNexus. The relational matrices, embeddings, layout engines, and analyzers that turn a pile of entries into a meaningful spatial graph.

> "Relational mapping/matricies — This is a huge algorithm. We will want to save results to a database." — original notepad

This folder is where [[architect]] and [[builder]] hash out the *how* before any of it gets coded.

## Key Files
- [[Association-Matrix]] - How we score relationships between any two nodes
- [[Embeddings]] - Text/image embedding choice and pipeline
- [[Spatial-Layout]] - Placing every node in 3D so related = close
- [[Poetry-Analysis]] - Theme/symbol extraction from journal entries
- [[Cross-Nexus-Linking]] - The Chase ↔ Mom topology problem
