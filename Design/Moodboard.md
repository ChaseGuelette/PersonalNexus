# Moodboard

> Part of [[Design]]

Visual references that anchor the aesthetic. All files live in the project's `images/` folder (NOT inside the brain — in the project root). Drop new references there as the design evolves.

See [[Assets]] for the index that maps each image to its meaning.

## The Core Set (currently in `images/`)

### Cosmic + Mechanical
- `5557689e-c041-4cb1-a0e5-8334109f41d8.png` — Watch in deep nebula. The background-feel target.
- `watchface.jpg` / `watchface.avif` — Holzkern wood-and-blue watch. The *texture* of cosmic-mechanical.

### Connection Tissue
- `dna.jpg` — Pure DNA helix, electric blue. Reference for connection-line glow.
- `helix.png` — **The single most important reference.** Icosahedron core with DNA helixes radiating, set in nebula. This is closest to what the actual nexus might look like.

### Sacred Geometry
- `icosahedron.jpg` — Clean line drawing. Structural inspiration for the core orb.
- `icosahedron-line-drawing-sacred-geometry-260nw-288304808.webp` — Same, vector form.

### Person Nodes
- `fire_ahh_oldman.png` — Portrait framed in constellations. The visual treatment for any "person" node.
- `mna.jpg` — Raw portrait without cosmic treatment. Useful as a "before" reference for the framing style.

### Navigation Model
- `skyrimskillselection.jpg` — The focus-plus-context navigation paradigm. Movement and selection should feel like this.

### What 2D Looked Like
- `braintreeos2d.png` — A 2D graph navigator. PersonalNexus is what we get when this lifts into 3D and gains art direction.

## Note for [[artist]] and [[builder]]

These references are *vibes*, not specs. The real visuals will be created in code. Use these to anchor the *feeling*; recreate them with shaders, particles, and 3D primitives — don't import the JPGs as textures.

When new visual ideas arrive, drop a reference image into `images/` and add an entry to [[Assets]] explaining what it captures.
